# v0.2.1

Windows GUI: сборка `pathprobe-gui.exe` (PyInstaller).

## Артефакты

- `pathprobe-0.2.1-windows-amd64.zip` — exe + `config.example.yaml` / `config.yaml` + `.sha256`
- Хеш SHA256 считается от **исполняемого файла** `pathprobe-gui.exe` внутри архива

## Запуск

1. Распаковать архив.
2. Отредактировать `config.yaml` (свои peers).
3. Запустить `pathprobe-gui.exe`.

Сборка из исходников: `.\scripts\build-windows-exe.ps1`
