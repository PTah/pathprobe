# v0.3.0

Режим **destinations**: диагностика внешних целей (Canva и др.).

## Что умеет

- `local_dns` vs `control_dns` — подмена / NXDOMAIN / SERVFAIL
- TCP / TLS(SNI) / HTTP до эталонных IP
- Вердикт «кто режет»: локальный DNS, DPI по SNI, HTTP-заглушка, отказ сервиса/WAF

## Артефакты

- `pathprobe-0.3.0-windows-amd64.zip` + SHA256 от `pathprobe-gui.exe`
- wheel/sdist в `dist/`

## Конфиг

См. `config.example.yaml` — блок `destinations` + `local_dns` / `control_dns`.
